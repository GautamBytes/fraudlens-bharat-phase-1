# Final Presentation Package

Use these files for the final Phase 1 + Phase 2 capstone meeting:

- `fraudlens-bharat-final-capstone.pptx`: completed 10-slide college template
- `final_presentation_script.md`: 15-minute speaker script
- `demo_video_runbook.md`: 3 to 4 minute recording and live-demo fallback

and entity relationships as future work and used obsolete metrics. Git history
retains that progress-review snapshot.

Presentation figures come from `outputs/presentation/`; current application
captures use the `outputs/screenshots/final_*.png` naming convention.
