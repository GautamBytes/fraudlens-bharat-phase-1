# Phase 1 Model And Data Card

## Model Name

FraudLens Bharat calibrated TF-IDF bootstrap predictor

## Intended Use

The model supports demo-stage cyber-fraud triage for pasted SMS or WhatsApp-style text.

It predicts a likely fraud category and feeds the result into entity extraction, URL risk analysis, scoring, and complaint-draft generation.

## Not Intended For

- Automatic police complaint submission
- Legal decision-making
- Real victim profiling
- Production fraud blocking
- Use on private victim data without consent and privacy controls

## Model Type

The selected classifier uses raw-normalized TF-IDF features, Logistic Regression, and sigmoid calibration.

It applies a threshold selected on the frozen validation split and abstains as `unknown` below that threshold.

The API uses a rule-only fallback only when persisted artifacts are unavailable or corrupt; weak generic keyword matches abstain.

## Labels

- `kyc_scam`
- `digital_arrest`
- `fake_job`
- `investment_scam`
- `loan_scam`
- `courier_scam`
- `upi_refund_scam`
- `otp_phishing`

`legitimate` remains a supported prediction-boundary label, but is absent from the current bootstrap and was not fabricated for training.

## Current Reproducible Evaluation

| Model | Final accuracy | Final macro F1 | Coverage | Abstention | Accepted accuracy | Frozen test rows |
|---|---:|---:|---:|---:|---:|---:|
| Rule-only runtime fallback | 0.2500 | 0.2500 | 25.0% | 75.0% | 100.00% | 8 |
| Raw-normalized TF-IDF | 0.3750 | 0.3333 | 100.0% | 0.0% | 37.50% | 8 |
| Marker TF-IDF (ablation; not selected) | 0.6250 | 0.6250 | 62.5% | 37.5% | 100.00% | 8 |
| Calibrated raw-normalized TF-IDF | 0.5000 | 0.5000 | 87.5% | 12.5% | 57.14% | 8 |

These values are sourced from `outputs/phase2/evaluation.json`, generated by
`python -m fraudlens.evaluation --dataset data/samples/phase2_dataset.csv --output outputs/phase2`.
The evaluation fits TF-IDF models and calibration on train, selects their
abstention thresholds on validation, and evaluates the frozen test split once.
The rule-only baseline instead calls the canonical runtime fallback and accepts
only its non-`unknown` labels; it is not evaluator-thresholded or calibrated.
Headline accuracy, macro metrics, per-class metrics, and confusion matrices use
final predictions, with rejected TF-IDF predictions recorded as `unknown`.
Underlying raw argmax diagnostics live separately under
`raw_prediction_metrics`. The evidence also reports expected calibration error
where applicable, coverage, and an explicit non-timed latency field so the JSON
remains deterministic. Final confusion matrices carry an `unknown` column so
all abstentions are visible and count as overall errors. The marker model is a
deliberately unselected ablation. The target is unmet: no legitimate examples
are available and every label is well below the 200-example target. These
metrics do not prove real-world generalization, production readiness, or
performance on a fabricated ninth class.

## Known Limitations

- Dataset is small, synthetic, and has no legitimate examples.
- Frozen test support is one example per fraud class.
- Real cyber-fraud messages may contain more noise, spelling variation, code-mixing, screenshots, and missing context.
- The model does not inspect images, attachments, voice notes, or transactions.
- The URL module is heuristic and not a trained phishing URL classifier.

## Safety Notes

Use dummy examples for demos.

Do not store real phone numbers, account numbers, UPI IDs, names, or screenshots in Phase 1.

The complaint draft is an assistive summary. The user must manually review and report through official channels when appropriate.

## Maintenance

When new data is added, retrain the baseline, inspect the confusion matrix, update `models/metrics.json`, and add regression tests for repeated errors.

## External Validation Boundary

The SMS Spam Collection [16] is used only for a separate binary spam/ham
research benchmark. A deterministic normalized-text group split prevents exact
duplicates from crossing partitions. The calibrated character TF-IDF research
candidate achieved 98.60% accuracy and 0.9682 Macro-F1 on 858 held-out messages,
but it is not the deployed eight-class model. The deployed runtime is evaluated
on the corpus only as a held-out ham selectivity stress test. Neither result is
production accuracy, and no externally trained model artifact is shipped.
